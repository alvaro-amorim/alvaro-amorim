## Projeto em destaque

### [FemHealth — Clinical AI](https://github.com/alvaro-amorim/femhealth-clinical-ai)

Projeto de machine learning voltado ao apoio à triagem de risco de câncer de mama, desenvolvido no Tech Challenge da pós-graduação **AI for Devs da FIAP** e avaliado com **nota máxima: 90/90**.

O repositório apresenta comparação entre modelos de classificação, análise de métricas, explicabilidade, documentação das limitações, Model Card, testes automatizados e integração contínua. A solução tem finalidade educacional e de apoio à análise, não substituindo avaliação ou diagnóstico médico.

**Destaques:** Python · Machine Learning · análise exploratória · explicabilidade · testes automatizados · GitHub Actions
